# ORION Clinic — инструкция по интерфейсу

В самой платформе откройте **«Инструкция» в левом меню** (`/help`).
Руководство читается внутри общего интерфейса; сверху доступны скачивание
автономного файла и открытие в отдельной вкладке. Дополнительный сервер 3212
для этого не нужен. Сборка приложения автоматически обновляет
`public/user-guide.html` из того же источника, что и автономный файл.
Это публичный учебный материал только с искусственными данными; раздел
платформы `/help` использует штатный вход.

Откройте **[ORION-CLINIC-GUIDE.html](ORION-CLINIC-GUIDE.html)** в браузере.
Это один автономный файл: 17 экранов, 67 цветных нумерованных маркеров,
пояснения ролей, последовательность действий, причины неактивных кнопок и
известные ограничения. Изображения и шрифт встроены. Нажмите снимок для
увеличения, Esc — для закрытия. Предусмотрена кнопка печати; отдельный PDF
в этой поставке не создавался и не проверялся.

## Для следующего разработчика

- Текст, порядок экранов и координаты рамок: `handbook-content.mjs`.
- Снимки: `images/handbook-2026-09-15/`. Файлы с историческим суффиксом `.png`
  содержат исходные JPEG-байты, возвращённые браузером; сборщик определяет MIME
  по сигнатуре и не перекодирует изображения. `handbook-preview.jpg` — проверенный
  снимок готовой увеличенной иллюстрации.
- Сборка из корня: `node scripts/build-user-handbook.mjs`.
- Предпросмотр: `node scripts/preview-user-handbook.mjs`, затем
  `http://127.0.0.1:3212/`. Сервер привязан только к loopback, не публикует репозиторий.
- Генератор проверяет границы всех рамок. После изменения UI снимите новый экран,
  скорректируйте координаты, пересоберите и визуально проверьте результат.
- Не заменяйте реальные экраны нарисованными макетами. Для снимков используйте
  только искусственных пациентов; не включайте токены и реальные данные.

Детальные предметные инструкции остаются в соседних `.ru.md`. Текущий статус
разработки и следующая ограниченная задача — `../MASTER_PLAN.md`.
