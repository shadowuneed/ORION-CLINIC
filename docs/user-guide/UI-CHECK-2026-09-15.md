## Наблюдения и оставшиеся проверки

- Первичное предположение о блокировке редактора после каждого сохранения не
  подтвердилось. Лог Vite показывает перезагрузку страницы при пересборке HTML
  руководства. При повторе без файловых изменений сохранение и проверка идут
  подряд, без нового требования продолжения. После настоящей перезагрузки
  требуется сверка состояния — это предусмотренное поведение.
- В локальной истории LIVE показаны пустые записи с 0 реплик / 00:00 и подписью
  «Завершён», хотя серверный приём ещё `in_progress`. Исправлено и проверено в
  браузере: заголовок «Локальные материалы приёмов», пустые записи «Материалов
  пока нет», остальные статусы относятся только к локальному сеансу. Серверный
  статус не менялся. Отдельно можно проверить необходимость хранения пустых сессий.
- Нажата ссылка скачивания руководства, но встроенный браузер не выдал событие
  загрузки. Атрибут `download` и автономный файл проверены; появление файла в
  пользовательской папке загрузок не подтверждено. Доступна отдельная HTML-копия.
- Инструмент браузера отклонил координатный щелчок внутри iframe из-за дробных
  координат; клавиатурное увеличение прошло. Это ограничение автоматизации,
  не доказательство неисправности клика обычной мышью.
- Не выполнены в этом проходе: реальный STT/микрофон, Groq, все 8 разделов до
  подписи, скачивание и визуальная проверка DOCX/PDF/ZIP, внешние провайдеры,
  сценарии каждой роли, все узкие размеры экрана. Не считать их пройденными.
- Поиск теперь буквальный; SQLite `lower` сохраняет прежнюю нечувствительность
  к регистру ASCII, но не обеспечивает полное Unicode case folding RU/KK.
