# Изолированная проверка ролей

Это тестовый контур, не способ входа в опубликованную платформу. Он использует
отдельные D1/R2, четыре искусственные учётные записи и только loopback-адрес.
Ключи ИИ и данные основной базы не переносятся.

Из корня ORION-CLINIC:

```powershell
node scripts/start-persona-tests.mjs 3213
```

Скрипт напечатает каталог `work/personas/run-...`. Сохраните его имя. Откройте
http://127.0.0.1:3213/__test/personas и выберите врача, медсестру,
администратора или регистратора. У каждой учётной записи только одна роль.
Сессия действует 30 минут; перезапуск сервера требует повторного входа.

Повторный запуск с той же базой (подставьте свой каталог):

```powershell
node scripts/start-persona-tests.mjs 3213 work/personas/run-ktJ4RX
node scripts/check-persona-runtime.mjs 3213
```

Вторая команда запускается в другом терминале после готовности сервера.
Она проверяет доступ к наблюдению и недействительность сессии после выхода:
врач и медсестра получают 200, администратор и регистратор — 403,
после выхода все — 401. Это не проверка всех операций платформы.

Повторный запуск не применяет миграции и не добавляет записи повторно.
После изменения схемы создайте новый контур первой командой. Не направляйте
ngrok на этот сервер. Не используйте реальные данные пациентов.

подтверждение под регистратором и проверить сохранение после перезагрузки.
